# Enterprise Playwright Automation Platform (EPAP)

## Overview

EPAP is an enterprise-grade web scraping platform built using open-source technologies.

## Technology Stack

- React
- FastAPI
- PostgreSQL
- Redis
- Playwright
- APScheduler
- Celery
- Docker

## Features

- Agent Management
- Automatic Scheduling
- Playwright Browser Automation
- PDF Download Manager
- Dashboard
- Reports
- Notifications
- REST API
- Multi-user Support
